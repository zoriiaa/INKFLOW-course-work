# INKFLOW - Professional materials for those who lead the line.

## Про проєкт

Магазин спеціалізується на товарах для скетчингу, пропонуючи лише перевірені інструменти. Наша мета - створити простір, де кожен штрих має значення.

**Статус: В розробці**

### **Ключові бренди:**

`Copic` • `Sakura` • `Faber-Castell` • `Posca` • `Manuscript`


##  Технологічний стек

  * **Framework:** ASP.NET Web API
  * **Database:** PostgreSQL + Entity Framework Core
  * **Mapping:** AutoMapper
  * **Frontend:** React.js, CSS3
  * **Design:** Figma


##  Функціонал

1.  **Каталог товарів:** Фільтрація за категоріями та брендами.
2.  **Детальна сторінка:** Опис характеристик кожного інструменту.
3.  **Система кошика:** Додавання, видалення та зміна кількості товарів.
4.  **Авторизація:** Реєстрація та логін користувачів.
5.  **Замовлення:** Оформлення покупок та збереження історії.

## Як запустити проєкт локально:

1. Клонуйте репозиторій.
2. У корені репозиторію скопіюйте `.env.example` у `.env`.
3. У `.env` задайте власні `DB_USER`, `DB_PASSWORD` та унікальний `JWT_SECRET` (щонайменше 32 символи). Не додавайте `.env` до Git.
4. Запустіть бекенд-проєкт через обрану IDE або за допомогою команди `dotnet run`.
5. Відкрийте в браузері адресу, яку видасть .NET (наприклад, `http://localhost:5275`)

## Запуск через Docker

Спершу скопіюйте `.env.example` у `.env` і задайте власні `DB_PASSWORD` та унікальний `JWT_SECRET` (щонайменше 32 символи). Потім із кореня репозиторію виконайте `docker compose up -d --build` і відкрийте `http://localhost:8080`. Docker збирає React-фронтенд у `dist` і копіює його в `wwwroot` ASP.NET. Порт PostgreSQL доступний лише локально на `127.0.0.1:5433`.

Після змін у коді `docker compose watch` автоматично перебудовує та перезапускає застосунок. Для одноразового оновлення без режиму стеження виконайте `docker compose up -d --build`.
