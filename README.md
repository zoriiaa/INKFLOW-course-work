# INKFLOW - Professional materials for those who lead the line.

## Про проєкт

Магазин спеціалізується на товарах для скетчингу, пропонуючи лише перевірені інструменти. Наша мета - створити простір, де кожен штрих має значення.
Побудований на ASP.NET MVC та PostgreSQL.

**Статус: В розробці**

### **Ключові бренди:**

`Copic` • `Sakura` • `Faber-Castell` • `Posca` • `Manuscript`


##  Технологічний стек

  * **Framework:** ASP.NET MVC
  * **Database:** PostgreSQL + Entity Framework Core
  * **Mapping:** AutoMapper
  * **Frontend:** React.js, CSS3
  * **Design:** Figma


##  Функціонал

1.  **Каталог товарів:** Фільтрація за категоріями та брендами.
2.  **Детальна сторінка:** Опис характеристик кожного інструменту.
3.  **Система кошика:** Додавання, видалення та зміна кількості товарів.
4.  **Авторизація:** Реєстрація та логін користувачів.
5.  **Замовлення:** Оформлення покупок та збереження історії.

## Як запустити проєкт локально:

1. Клонуйте репозиторій.
2. У папці з бекендом знайдіть файл `.env.example`, скопіюйте його та перейменуйте на `.env`.
3. У створеному файлі `.env` вкажіть ваші реальні дані для підключення до PostgreSQL (`DB_USER`, `DB_PASSWORD` тощо).
4. Запустіть бекенд-проєкт через обрану IDE або за допомогою команди `dotnet run`.
5. Відкрийте в браузері адресу, яку видасть .NET (наприклад, `http://localhost:5275`)
